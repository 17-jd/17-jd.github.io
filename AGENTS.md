# AGENTS.md

## Cursor Cloud specific instructions

This is a minimal **GitHub Pages** static site repository (`17-jd.github.io`) with a custom domain configured via the `CNAME` file pointing to `itsjaydip.me`.

### Repository contents

- `README.md` — site description
- `CNAME` — custom domain configuration for GitHub Pages

### Local development

Run the site locally with Jekyll (already installed in the environment):

```bash
jekyll serve --host 0.0.0.0 --port 4000
```

The site will be available at `http://localhost:4000`. Jekyll watches for file changes and auto-regenerates.

### Notes

- There is no `Gemfile`, `package.json`, or build configuration — this is a bare-bones GitHub Pages repo.
- There are no lint checks, automated tests, or build steps.
- GitHub Pages renders `README.md` as the site index when no `index.html`/`index.md` is present; locally, Jekyll shows a directory listing instead. To preview rendered content locally, add an `index.md` with content.
- The `_site/` and `.jekyll-cache/` directories are generated by Jekyll and should not be committed.
